# 버튼으로 비밀번호 초기화하기

기존 Python 도구 대신 사용하는 관리자 전용 창입니다.
아직 배포와 실제 Firebase 초기화 확인이 필요합니다.

1. sonices123@gmail.com으로 https://script.google.com/home 에 접속해 새 프로젝트를 만듭니다.
2. Code.gs 내용을 이 폴더의 Code.gs로 교체합니다.
3. HTML 파일 Reset을 추가하고 Reset.html 내용을 붙여넣습니다.
4. 프로젝트 설정에서 appsscript.json 표시를 켜고 이 폴더의 appsscript.json 내용을 붙여넣습니다.
5. 배포 → 새 배포 → 웹 앱. 실행 사용자: 나, 액세스 권한: 나만. 공개/모든 사용자로 배포하지 않습니다.
6. 관리자 Google 계정으로 필요한 권한을 승인합니다. 조직 정책 등으로 막히면 설정을 우회하지 말고 오류를 확인합니다.
7. 발급된 /exec 주소를 SKW → 사용자 관리 → 초기화 연결 설정에 저장합니다.
8. 비밀번호 초기화 버튼으로 관리자 창을 엽니다. 대상 아이디와 임시 비밀번호를 입력하고 확인하면 기존 UID의 비밀번호만 변경합니다.

연결 주소는 설정한 브라우저에만 저장됩니다. 다른 PC에서는 한 번 더 연결합니다.
앱의 일반 사용자 관리 권한자는 버튼을 사용할 수 없습니다.
Apps Script 접근 권한 '나만' 설정과 서버의 소유자 이메일 검증을 함께 사용합니다.
Firebase IAM 권한은 별도로 필요하며, Google OAuth 토큰은 서버 밖으로 반환하지 않습니다.
로그인 후 비밀번호 변경은 사용자가 직접 수행하며 강제 변경은 아직 구현하지 않았습니다.
API 실제 호출, Google 승인, 브라우저 새 창 동작은 배포 후 검증해야 합니다.
